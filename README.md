# WebGoat-Scripts

[![Project Tracker](https://img.shields.io/badge/repo%20status-Project%20Tracker-lightgrey)](https://hthompson.dev/project-tracker#project-681847718)

"WebGoat is a deliberately insecure web application maintained by OWASP designed to teach web application security lessons."
